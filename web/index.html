Real-time sign language recognition in the browser

Sign in front of your camera and the page recognises the word — powered by the same neural network the desktop app trains. Hand tracking (MediaPipe) and the GRU model run entirely on your device via WebAssembly. Builds a spoken sentence as you sign.

Desktop app + train your own signs

Full experience: webcam recognition, sentence builder, text-to-speech, mic input and text-to-sign glosses — all local and private.

git clone https://github.com/YOGESH11K/sign-language.git
cd sign-language
pip install -r requirements.txt
python main.py

# add a new sign (auto-record 20 samples, no key presses)
python -m training.collect_data --label HELLO --samples 20 --auto
python -m training.preprocess
python -m training.train --kind sequence
python -m training.export_onnx      # ships the new model to this page
python main.py
