Run the desktop app

Python 3.x on Windows. The web UI above is a demonstration; the full experience with live sign recognition, sentence building, TTS and a two-tab interface is the Python application.

git clone https://github.com/YOGESH11K/sign-language.git
cd sign-language
pip install -r requirements.txt
python main.py

Add a new sign (no typing required):

python -m training.collect_data --label HELLO --samples 20 --auto
python -m training.preprocess
python -m training.train --kind sequence
python main.py

Vocabulary, dataset & architecture details live in the repo README. Raw webcam frames are never stored — only landmark coordinates.

Stem SignLanguage · built with MediaPipe Tasks, scikit-learn & PyTorch GRU · no shortcuts, honest accuracy — accuracy is measured on your own held-out data, never hard-coded.
